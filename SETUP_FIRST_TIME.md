# MAELEZO YA KUFUNGUWA KWENYE MOD EDITOR (mara ya kwanza)

1. Sakinisha BUSSID Mod Editor (maleostudio.com) kwenye Windows.
2. Fungua Mod Editor -> New Project -> chagua "Map" template.
3. Funga mradi huo, kisha nakili folda `Assets/Map` ya package hii
   ndani ya folda ya mradi huo (badilisha ile iliyopo).
4. Fungua mradi tena -> menyu Tools -> MwanzaDar -> 1 hadi 4.
5. Drag prefabs kwenye PrefabLibrary (ndani ya MapBuilder.cs).
6. Export kutoka kwenye dirisha la Mod Editor.
